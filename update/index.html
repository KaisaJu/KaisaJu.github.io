How This Site Works

This website is hosted on GitHub Pages and served from the repository KaisaJu/KaisaJu.github.io (branch master). There is no Jekyll or other build step — a file named .nojekyll in the repository root turns that off — so every committed change goes live automatically in about one minute.

  • index.html — the home page (biography, education, research interests)
  • publications/index.html — the publications page
  • talks/index.html — the talks page
  • cv/index.html — the CV page
  • assets/js/i18n.js — all bilingual (Chinese / English) text
  • images/ — profile photo and banner image
  • assets/css/new-style.css — colors, fonts and layout

Option 1: Edit Directly in the Browser

Open the repository on GitHub, click the file you want to change, press the pencil icon (“Edit”), modify the text, then click “Commit changes”. GitHub Pages rebuilds the site automatically — no extra software needed.

Option 2: Edit Locally with Git

Clone the repository to your computer, edit the files, then push:

git clone https://github.com/KaisaJu/KaisaJu.github.io.git
cd KaisaJu.github.io
## edit files here, then:
git add -A
git commit -m "Update content"
git push origin master

Updating Bilingual Text

Most of the visible text is bilingual. On the page it appears as attributes like data-i18n="home.bio"; the actual Chinese and English strings live in assets/js/i18n.js, inside the I18N_DICT object (two blocks: en and zh). When changing any text, update both the en and zh entries, otherwise the language toggle on the top right will fall back to the old text.

Adding a Publication or a Talk

Open publications/index.html, copy an existing <article class="pub-card"> block, paste it below, and fill in the new title, venue and badges. Adding a talk works the same way in talks/index.html (copy a talk-card block). If the new entry needs its own bilingual text, add matching keys to both the en and zh blocks of assets/js/i18n.js, and reference them with data-i18n="...".

Replacing the Photo or the Banner

Replace images/profile.JPG (portrait photo) or images/banner.png (decorative divider) with a new file of the same name, or upload a new file and update the corresponding <img src="..."> references.

If Something Goes Wrong

Every change is stored as a commit, so nothing is ever lost. On the repository page, open “Commits”, find the last good version, click “…” and choose “Revert” — the website rolls back automatically after the next build.
